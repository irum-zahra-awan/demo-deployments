## Quick reference: free hosting by stack

| Your stack | Where it goes live |
|---|---|
| Python / Streamlit | Streamlit Community Cloud (free) |
| AI Studio build | Built-in Export & Publish |
| Lovable / Bubble | Native publish button — check your custom domain settings |
| Airtable + Softr | Softr's free-tier publish |
| Plain HTML/JS/React | Vercel, Netlify, or Cloudflare Pages (all free) |
| Need a real database + login | Supabase or Firebase free tier |

**One habit that saves demos:** never put an API key directly in your code. Every platform above has a "secrets" or "environment variables" spot — use it.
